HOW THIS WORKS

I am now going to state how everything works in this game/website.

STAPLES

The staple counter starts at 0 and clicking the button called "make staple" will add +1 staple. updateUI() refreshes the screen and using toLocaleString() along with some formatting so when a number reaches a number with three "0s", it will add a comma (,) for readability (eg: 1000 > 1,000).

AUTOSTAPLERS

Autostaplers work by subtracting a number of staples (starts at 10 staples, price increases by 1.25x each time an autostapler is bought.) and periodically adds 1 staple per second, increasing the staples per second depending on how many autostaplers you have (eg 0 autostaplers = 0 staples per second and 10 autostaplers = 10 staples per second).

SAVING + LOADING

Saving + loading I mentioned briefly earlier but I will go in a bit more depth here. When you press the "save" button it will download a .txt file. In this file is some data, this data shows how many staples, autostaplers, autostapler price, etc is shown. Yes this means you can manually edit the save and give yourself 999,999,999,999,999 staples and autostaplers. I kept this as a psuedo accessebility feature for people who don't like to grind. However, trying to mess around too much and trying to load it can crash the website. You reap what you sow, I guess. Oh yeah, also there are notes that will download upon reaching a certain threshold of staples. Some of these requirements are ridiculously large and so you HAVE to edit your save file to get the manual clicks required. Loading will bring up a file explorer menu which from there you can upload your .txt save which will resume the game with the present stats. The way it actually works is you save the game state and stats with JSON.stringify and create a blob (binary large object) which allows you to store binary data, a .txt file is downloaded to your computer, FileReader is used to read the file that is selected in the load menu, it will then restore the values and updateUI().

DRONES

The Alpha Drone is an upgrade which increases all total staple production by +50%. This is a really useful upgrade, as all multiplication is in clicker games. I'm gonna be honest, this was really complex for me to wrap my head around so I did actually steal/generate a lot of this code. Just treat all the drones as bonus content. The Beta Drone is actually pretty bad ngl so far and I'm probably going to buff it in a later update. At the time of writing it gives your manual staple clicks a 3x multiplier. This is... pretty bad, as it falls off HARD late game as it's just a flat number. The Gamma Drone is pretty useful, but doesn't really supply a buff as much as it does just give you a little quality of life feature that speeds up automation. I like it though.
